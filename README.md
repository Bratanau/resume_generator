# CVision

Веб-приложение для анализа резюме, уточнения опыта, создания HTML-резюме и ссылки для работодателя.

## Запуск после клонирования

Нужны Git и Node.js **20.19+**.

```powershell
git clone https://github.com/Bratanau/resume_generator.git
cd resume_generator
npm install
Copy-Item .env.example .env
npm run dev
```

Откройте **http://localhost:3000**.

Для AI-анализа, вопросов кандидату и оценки соответствия вакансии задайте `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в `.env`. Модель и её версия настраиваются через `YANDEX_MODEL` и `YANDEX_MODEL_VERSION`; endpoint по умолчанию — Yandex Foundation Models. Для локальных карьерных инструментов сохраняется резервный режим, но AI-решение по отклику не подменяется локальным результатом при ошибке провайдера.

## Хранение данных

Вакансии и отклики сохраняются в локальной SQLite-базе `data/cvision.sqlite` и остаются после перезапуска сервера. Путь можно изменить через `DATABASE_PATH`. В базе хранятся сведения о вакансии, имя и email соискателя, заданные вопросы, ответы и результат отбора; исходный текст или PDF резюме в базе не сохраняются. Резюме и ответы передаются в Yandex Foundation Models для анализа.

Это локальное хранилище для одного экземпляра сервера, а не готовая production-инфраструктура: в приложении пока нет авторизации HR, разграничения доступа, шифрования базы и настроек срока хранения. Данные телеметрии старых экранов остаются в памяти процесса и теряются при перезапуске. До внедрения необходимых мер защиты и правил обработки персональных данных используйте только вымышленные данные.
